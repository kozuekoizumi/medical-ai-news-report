================================================================================
4つのパーツ整理
ツール名：医療AI最新ニュース自動収集・まとめレポートツール
================================================================================

## このツールが解決すること

「医療AIの最新情報を知りたいけど、毎回自分でGoogle検索して記事を探すのが面倒」
→ 毎週月曜の朝7時に自動でニュースを集めて要約し、LINEに届ける


================================================================================
■ 4つのパーツ（決定版）
================================================================================

┌─────────────────────────────────────────────────────────────┐
│  トリガー  ──→  ソース元  ──→  処理する場所  ──→  届ける先  │
│  GitHub       Google         GitHub Actions     LINE          │
│  Actions      News RSS       上のPythonスクリプト Messaging  │
│                                                 API           │
└─────────────────────────────────────────────────────────────┘


--------------------------------------------------------------------------------
1. トリガー：GitHub Actions（時間ベースの自動実行）
--------------------------------------------------------------------------------

【何をするか】
毎週月曜の朝7時（日本時間）に自動でツールを起動する

【なぜGitHub Actionsを選んだか】
・完全無料（パブリックリポジトリなら月2000分以上の無料枠）
・YAML形式で「毎週月曜7時に動かす」と書くだけで設定できる
・エラーが起きたときにメールで通知してくれる
・世界中のエンジニアが使っている実績のある仕組み

【設定するcron式】
0 22 * * 0   ← UTC表記（日曜22:00 UTC ＝ 月曜7:00 JST）

【参考URL】
https://dylanbritz.dev/writing/scheduled-cron-jobs-github/


--------------------------------------------------------------------------------
2. ソース元：Google News RSS
--------------------------------------------------------------------------------

【何をするか】
「医療AI」「透析AI」「看護AI」などのキーワードでGoogleニュースを検索し
最新ニュースの一覧（タイトル・URL・要約）を取得する

【なぜGoogle News RSSを選んだか】
・完全無料・APIキー不要
・Pythonライブラリ（google-news-api）で簡単に使える
・日本語キーワードで日本の医療ニュースを取得できる
・1週間以内の新着記事に絞り込める（after/beforeフィルター）

【取得するキーワード（予定）】
・「医療 AI」
・「透析 AI」「透析 人工知能」
・「看護師 AI」
・「診療報酬 AI」

【参考URL】
https://github.com/ma2za/google-news-api


--------------------------------------------------------------------------------
3. 処理する場所：GitHub Actions上のPythonスクリプト
--------------------------------------------------------------------------------

【何をするか】
① Google News RSSからニュースを取得する
② Claude API（AI）に「透析室ナース向けに要約して」と依頼する
③ 要約結果をreport-template.htmlのプレースホルダー（{{...}}）に流し込む
④ 完成したHTMLをLINEに送れる形式に変換する

【なぜPythonを選んだか】
・GitHub Actionsと相性が良い
・ニュース取得もAI呼び出しもメール送信も、全部Pythonで書ける
・AIが日本語でコードを書いてくれるので初心者でも進めやすい

【使うPythonライブラリ（予定）】
・google-news-api     ← ニュース取得
・anthropic           ← Claude APIでAI要約
・requests            ← HTTP通信全般


--------------------------------------------------------------------------------
4. 届ける先：LINE Messaging API
--------------------------------------------------------------------------------

【何をするか】
完成したレポートをLINEのチャットに自動送信する

【なぜLINE Messaging APIを選んだか】
・月200通まで無料（週1回なら年52通 → 余裕で無料枠内）
・LINEは毎日使うアプリなので見逃しにくい
・LINE Notify（旧サービス）は2025年3月に廃止済み
  → 今はMessaging APIが公式の正しい方法
・セットアップ約15分で完了できる

【セットアップの流れ】
1. LINE公式アカウントを個人で作成（無料）
2. Messaging APIを有効化
3. Channel Access TokenとChannel Secretを取得
4. GitHubのSecretsに登録（コードに直書きしない！）

【参考URL】
https://developers.line.biz/ja/docs/messaging-api/getting-started/
https://developers.line.biz/ja/docs/messaging-api/pricing/

================================================================================

[毎週月曜 朝7時]
      ↓
GitHub Actionsが起動
      ↓
PythonスクリプトがGoogle News RSSから「医療AI」関連記事を取得
      ↓
Claude APIが「透析室ナース向け」に要約・カテゴリ分け
      ↓
report-template.htmlのプレースホルダーに流し込む
      ↓
LINE Messaging APIで自分のLINEに送信
      ↓
[朝7時にLINEにレポートが届く 🏥]
