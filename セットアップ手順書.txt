================================================================================
セットアップ手順書
ツール名：医療AI週次ニュースレポート自動送信ツール
================================================================================

このドキュメントを上から順に進めると、ツールが動くようになります。
所要時間：約30〜45分

================================================================================
■ 事前確認（持っているものをチェック）
================================================================================

  ✅ GitHubアカウント
  ⬜ LINE公式アカウント → STEP 0 で作成します
  ✅ Claude APIキー（取得済み）


================================================================================
STEP 0：LINE公式アカウントを作成してMessaging APIを有効化する
================================================================================

所要時間：約15分

【0-1】LINE公式アカウントを作成する

  1. ブラウザで以下を開く
     → https://www.linebiz.com/jp/entry/

  2. 「LINE公式アカウントを開設する」ボタンをクリック

  3. 自分の個人LINEアカウントでログインする
     （「LINEアカウントで登録」を選ぶのが一番簡単）

  4. 必要情報を入力する：
     - アカウント名：例「医療AIニュース」（自分だけが使う名前なので何でもOK）
     - 業種：「個人」など適当に選んでOK
     - メールアドレスを登録

  5. 「完了」まで進めてアカウントを作成する


【0-2】Messaging APIを有効化する

  1. LINE Official Account Manager を開く
     → https://manager.line.biz/

  2. 作成したアカウントを選択

  3. 左メニューの「設定」→「Messaging API」をクリック

  4. 「Messaging APIを利用する」ボタンをクリック

  5. プロバイダーの選択画面が出る
     → 「新規プロバイダーを作成」を選んで名前をつける（例：「個人ツール」）
     ⚠️ プロバイダーは後から変更できないので、「個人ツール」など汎用的な名前がおすすめ

  6. 「同意する」→「OK」で有効化完了


【0-3】自分のLINEで公式アカウントを「友だち追加」する

  1. LINE Official Account Manager の画面に「BotのベーシックID」が表示される
     （例：@abc-12345）

  2. スマートフォンの自分のLINEアプリで、そのIDを検索して友だち追加する

  ⚠️ 友だち追加しないとボットからメッセージを受け取れません


================================================================================
STEP 1：LINE_USER_ID を確認する
================================================================================

LINE_USER_ID とは「あなた自身のLINE上のID」です。
ボットからあなたにメッセージを送るために必要です。

手順：
  1. ブラウザで LINE Developers コンソールを開く
     → https://developers.line.biz/console/

  2. 画面右上のプロフィールアイコンをクリック

  3. 「Your user ID」という欄に表示されている文字列をコピーする
     （例：U1234567890abcdef1234567890abcdef）

  ⚠️ これはボットのIDではなく、あなた自身のユーザーIDです。
     間違えやすいので注意してください。

  4. コピーしたIDをメモ帳などに控えておく


================================================================================
STEP 2：LINE Channel Access Token を確認する
================================================================================

  1. LINE Developers コンソール → 自分のチャンネルを選択

  2. 「Messaging API」タブを開く

  3. 「Channel access token」の「Issue」ボタンをクリック
     （すでに発行済みの場合はそのまま使う）

  4. 表示されたトークンをコピーしてメモ帳に控えておく


================================================================================
STEP 3：GitHubにリポジトリを作成する
================================================================================

  1. GitHub（https://github.com）にログイン

  2. 右上の「+」→「New repository」をクリック

  3. 以下の設定でリポジトリを作成する：
     - Repository name: medical-ai-news-report（任意の名前でOK）
     - Visibility: Public（GitHub ActionsをPaaS無料で使うため）
     - Add a README file: チェックを入れる

  4. 「Create repository」をクリック


================================================================================
STEP 4：GitHub Secrets に3つのキーを登録する
================================================================================

APIキーは絶対にコードに書いてはいけません。
GitHub Secrets に登録することで、安全に管理できます。

手順：
  1. 作成したリポジトリのページを開く

  2. 上部メニューの「Settings」タブをクリック

  3. 左メニューの「Secrets and variables」→「Actions」をクリック

  4. 「New repository secret」ボタンで以下の3つを登録する：

     ┌────────────────────────────────────────────────────────────┐
     │  Name                      │  Secret（値）                 │
     ├────────────────────────────────────────────────────────────┤
     │  ANTHROPIC_API_KEY         │  sk-ant-api03-... で始まる文字列 │
     │  LINE_CHANNEL_ACCESS_TOKEN │  STEP2で控えたトークン          │
     │  LINE_USER_ID              │  STEP1で控えたユーザーID         │
     └────────────────────────────────────────────────────────────┘

  ⚠️ Secretは登録後に内容を確認できません。必ずメモ帳に控えておいてください。


================================================================================
STEP 5：ファイルをGitHubにアップロードする
================================================================================

このフォルダにある以下のファイルをGitHubにアップロードします。

  アップロードするファイル：
    ├── src/
    │   └── report_generator.py
    ├── requirements.txt
    ├── report-template.html
    ├── .gitignore
    └── .github/
        └── workflows/
            └── weekly_report.yml

  手順（Cursorから行う場合）：
    1. Cursorのターミナルで以下を実行する：

       cd "c:\Users\combi\OneDrive\Desktop\ADS\202604面倒な報告を自動化するツール"
       git init
       git remote add origin https://github.com/[あなたのユーザー名]/medical-ai-news-report.git
       git add .
       git commit -m "医療AI週次レポートツールを追加"
       git push -u origin main

    ⚠️ [あなたのユーザー名] の部分は実際のGitHubユーザー名に変えてください


================================================================================
STEP 6：手動実行でテストする
================================================================================

  1. GitHubのリポジトリページを開く

  2. 上部の「Actions」タブをクリック

  3. 左側の「医療AI週次レポート送信」をクリック

  4. 右側の「Run workflow」ボタンをクリック→「Run workflow」

  5. 数十秒〜1分後に実行結果が表示される
     - 緑のチェック（✅）：成功！LINEを確認してください
     - 赤のバツ（❌）：エラー。クリックして詳細を確認してください

  よくあるエラーの原因：
    - STEP4のSecretの登録ミス（名前のスペルミスなど）
    - LINE_USER_IDの取り違え（ボットIDとユーザーIDを間違えている）
    - LINE公式アカウントにまだ友だち追加していない
      → 自分のLINEで公式アカウントを友だち追加してから再実行してください


================================================================================
STEP 7：自動実行の確認
================================================================================

  毎週月曜の朝7時（日本時間）に自動でLINEにレポートが届きます。

  スケジュール設定の確認場所：
    .github/workflows/weekly_report.yml の cron: '0 22 * * 0'
    UTC 日曜22:00 ＝ JST 月曜07:00

  ⚠️ GitHub Actionsのスケジュール実行は数分〜数十分遅れることがあります。
