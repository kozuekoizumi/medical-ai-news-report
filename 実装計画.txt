実装計画：医療AI最新ニュース自動収集・まとめレポートツール
================================================================================

## 作るもの

毎週月曜の朝7時に、医療AI関連ニュースを自動で集めて要約し、
LINEにテキスト形式で送るツール。

================================================================================
■ 各ファイルの役割と処理の流れ
================================================================================

【1】report_generator.py（メインスクリプト）

処理ステップ：
  Step1: fetch_news()
    - feedparser ライブラリを使って Google News RSS から記事取得
    - 取得するキーワード：「医療 AI」「透析 人工知能」「看護師 AI」「診療報酬 AI」
    - 各キーワードで最新3件、合計最大12件を取得
    - 1週間以内の記事のみに絞り込む

  Step2: summarize_with_claude()
    - 取得した記事のタイトル・URL・概要を Claude API（Haiku モデル）に渡す
    - 「透析室ナース向けに要約して」という指示とともに送信
    - report-template.html の構造（カテゴリ3種・今週のポイント）に合わせて出力させる
    - Claude が返すのはテキスト形式の要約

  Step3: send_line_message()
    - LINE Messaging API（push message）で自分のLINEに送信
    - メッセージ内容：
        🏥 医療AI週次レポート（日付）
        ─────────────────
        ⚡ 今週のポイント
        （Claudeが要約した内容）
        ─────────────────
        💧 透析・腎臓領域
        （ニュース1〜2件）
        ─────────────────
        🩺 看護・病院運営
        （ニュース1〜2件）
        ─────────────────
        🤖 医療AI全般
        （ニュース1〜2件）

使用する環境変数（GitHub Secretsに登録するもの）：
  - ANTHROPIC_API_KEY       ← Claude APIキー
  - LINE_CHANNEL_ACCESS_TOKEN ← LINEボットのアクセストークン
  - LINE_USER_ID            ← 送信先（自分）のLINE ユーザーID


【2】requirements.txt

  feedparser==6.0.11    ← Google News RSSの取得
  anthropic==0.49.0     ← Claude API 呼び出し
  requests==2.32.3      ← HTTP通信（LINE API送信）


【3】weekly_report.yml（GitHub Actions ワークフロー）

  トリガー：
    - schedule: cron: '0 22 * * 0'
      （UTC日曜22時 ＝ 日本時間月曜朝7時）
    - workflow_dispatch（手動実行ボタンも追加 ← テスト用）

  実行ステップ：
    1. リポジトリをチェックアウト（コードをダウンロード）
    2. Python 3.12 をセットアップ
    3. requirements.txt のライブラリをインストール
    4. report_generator.py を実行
    5. 成功/失敗をGitHub上で確認できる


================================================================================
■ データの流れ（全体図）
================================================================================

[月曜 7:00 JST]
      ↓
GitHub Actions が起動
      ↓
Python: Google News RSS から「医療AI」関連記事を最大12件取得
      ↓
Python: 記事のタイトル・URL・概要を Claude API（Haiku）に送信
         「透析室ナース向けにカテゴリ別に要約して」
      ↓
Claude: カテゴリ別に要約テキストを返す
      ↓
Python: LINE Messaging API でフォーマット済みテキストを送信
      ↓
[自分のLINEに週次レポートが届く 🏥]


================================================================================
■ 判断事項・制約
================================================================================

◎ モデル選択：Claude Haiku を使う理由
  - 最も安価（1回あたり約0.5円以下）
  - ニュース要約程度の作業なら十分な精度
  - 将来 Sonnet に変えることも容易

◎ LINE送信方式：Push Message を使う理由
  - 決まった時刻に自動送信できる
  - Reply Message はユーザーのメッセージへの返信にしか使えないため不適

◎ HTMLはこのフェーズでは画像化しない理由
  - Playwright（HTML→画像変換）は設定が複雑で初心者には難易度が高い
  - まずテキスト送信で動くことを確認し、後から画像化を追加できる
  - report-template.html は「AIへの模範解答」として引き続き機能する

◎ APIキーの管理
  - コードには一切書かない
  - GitHub Secrets に登録することで安全に管理する
